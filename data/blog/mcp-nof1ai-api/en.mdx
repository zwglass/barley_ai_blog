**_In the past few days the nof1.ai site has been running live tests with DeepSeek, Grok, Qwen3, Claude, Gemini, and GPT-5, giving each AI USD 10k to auto-trade crypto. It is wildly popular, but can AI fact-check whether the trading is real?_**

### Install the basic tools (git, Python, Node.js, VS Code); download from the official sites below

```
# Node.js official site (version must be 20 or above)
https://nodejs.org/
```

### Install the gpt-5-codex command

```
npm install -g @openai/codex
```

### Install chrome-devtools-mcp (Chrome browser required on the computer)

```
codex mcp add chrome-devtools -- npx chrome-devtools-mcp@latest
```

### Configure gpt-5-codex environment variables (set them first when using a relay inside China)

```
# Open the beginning of the ~/.codex/config.toml file and add the following configuration:

model_provider = "crs"
model = "gpt-5-codex"
model_reasoning_effort = "high"
disable_response_storage = true
preferred_auth_method = "apikey"
[model_providers.crs]
name = "crs"
base_url = "https://{relay-domain}/openai"
wire_api = "responses"
requires_openai_auth = true
env_key = "CRS_OAI_KEY"
```

### Enter Codex in the terminal

```
export  CRS_OAI_KEY={api_key}
codex
```

### Prompt for letting codex with chrome-devtools-mcp analyze the nof1.ai site

    - Use chrome-devtools-mcp to open https://nof1.ai and inspect which provider powers the site's trading API.
    - What company is Hyperliquid?
