Codex를 사용해 클래식 미니게임 팩맨을 재현합니다.

### 필수 도구 Git, Python, Node.js, VS Code 설치: 아래 공식 사이트에서 다운로드

```
# Git 공식 사이트
https://git-scm.com/

# Python 공식 사이트
https://www.python.org/

# Node.js 공식 사이트
https://nodejs.org/

# VS Code 공식 사이트
https://code.visualstudio.com/
```

### Git으로 팩맨 게임 저장소 클론하기

```
git clone https://github.com/akDeveloper/80s-pacman.git
```

### gpt-5-codex 명령 설치

```
npm install -g @openai/codex
```

### gpt-5-codex 환경 변수 설정 (중국 본토에서는 먼저 중계 설정을 구성)

```
# ~/.codex/config.toml 파일을 열고 맨 위에 다음을 추가하세요:

model_provider = "crs"
model = "gpt-5-codex"
model_reasoning_effort = "high"
disable_response_storage = true
preferred_auth_method = "apikey"
[model_providers.crs]
name = "crs"
base_url = "https://{relay-domain}/openai"
wire_api = "responses"
requires_openai_auth = true
env_key = "CRS_OAI_KEY"
```

### 터미널에서 Codex 실행

```
export CRS_OAI_KEY={api_key}
codex
```

### Python 가상 환경 생성 및 의존성 설치

```
# --- 클론한 80s-pacman 폴더에서 작업 ---

# 가상 환경 생성
mkdir .venv && cd .venv
python3 -m venv .
cd ..

# 가상 환경 활성화
source .venv/bin/activate

# 의존성 설치
pip install pygame
```

### 프로젝트 실행

```
python main.py
```

### Vibe Coding 프롬프트

    - 프로젝트에 배경 음악과 효과음을 추가하세요
    - 무적 모드를 추가하고 시작 화면에 전환 키 조합을 표시하세요
    - 승리 또는 패배 후 화면에 메시지를 표시하세요
    - 게임을 10단계로 늘리고 단계가 올라갈 때마다 적 속도를 두 배로 높이고 적을 한 명씩 추가하세요. 각 게임이 끝난 뒤에는 다음 단계로 이동하거나 재시작·계속할 키를 안내하세요
