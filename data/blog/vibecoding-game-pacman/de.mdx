Nutze Codex, um das klassische Minispiel Pac-Man nachzubauen.

### Installiere die Grundlagen: Git, Python, Node.js, VS Code; lade sie über die offiziellen Seiten unten herunter

```
# Offizielle Git-Website
https://git-scm.com/

# Offizielle Python-Website
https://www.python.org/

# Offizielle Node.js-Website
https://nodejs.org/

# Offizielle VS-Code-Website
https://code.visualstudio.com/
```

### Klone das Pac-Man-Spiel-Repository mit Git

```
git clone https://github.com/akDeveloper/80s-pacman.git
```

### Installiere den Befehl gpt-5-codex

```
npm install -g @openai/codex
```

### Konfiguriere die gpt-5-codex-Umgebungsvariablen (richte zuerst die Relay-Einstellungen ein, wenn du in Festlandchina bist)

```
# Öffne ~/.codex/config.toml und füge oben Folgendes hinzu:

model_provider = "crs"
model = "gpt-5-codex"
model_reasoning_effort = "high"
disable_response_storage = true
preferred_auth_method = "apikey"
[model_providers.crs]
name = "crs"
base_url = "https://{relay-domain}/openai"
wire_api = "responses"
requires_openai_auth = true
env_key = "CRS_OAI_KEY"
```

### Starte Codex im Terminal

```
export CRS_OAI_KEY={api_key}
codex
```

### Erstelle eine Python-virtuelle Umgebung und installiere Abhängigkeiten

```
# --- Arbeiten im geklonten Ordner 80s-pacman ---

# Erstelle die virtuelle Umgebung
mkdir .venv && cd .venv
python3 -m venv .
cd ..

# Aktiviere die virtuelle Umgebung
source .venv/bin/activate

# Installiere die Abhängigkeiten
pip install pygame
```

### Starte das Projekt

```
python main.py
```

### Vibe-Coding-Impulse

    - Füge dem Projekt Hintergrundmusik und Soundeffekte hinzu
    - Füge einen Unbesiegbarkeitsmodus hinzu und zeige auf dem Startbildschirm die Tastenkombination zum Umschalten an
    - Zeige nach einem Sieg oder einer Niederlage eine Meldung auf dem Bildschirm an
    - Erhöhe das Spiel auf zehn Level; mit jedem Level verdoppelt sich die Gegnergeschwindigkeit und ein weiterer Gegner kommt hinzu; zeige nach jeder Partie, welche Taste zum nächsten Level führt oder das Spiel neu startet bzw. fortsetzt
