### 3. 拉取comfyui, 下载模型

```
# 拉取comfyui
cd aoi_useless_docker

export HF_TOKEN="Access Tokens"

**ComfyUI/models/checkpoints**
cd ComfyUI/models/checkpoints/
wget --tries=5 --timeout=30 --retry-connrefused --header="Authorization: Bearer $HF_TOKEN" -O ace_step_v1_35b.safetensors "https://huggingface.co/Comfy-Org/ACE-Step_ComfyUI_repackaged/resolve/main/all_in_one/ace_step_v1_3.5b.safetensors"

**diffusion_models**   
cd ComfyUI/models/diffusion_models/    
wget --tries=5 --timeout=30 --retry-connrefused --header="Authorization: Bearer $HF_TOKEN" -O Wan2_2-Animate-14B_fp8_scaled_e5m2_KJ_v2.safetensors "https://huggingface.co/Kijai/WanVideo_comfy_fp8_scaled/resolve/main/Wan22Animate/Wan2_2-Animate-14B_fp8_scaled_e5m2_KJ_v2.safetensors"

**loras**
cd ComfyUI/models/loras/   
wget --tries=5 --timeout=30 --retry-connrefused --header="Authorization: Bearer $HF_TOKEN" -O lightx2v_I2V_14B_480p_cfg_step_distill_rank64_bf16.safetensors "https://huggingface.co/Kijai/WanVideo_comfy/resolve/main/Lightx2v/lightx2v_I2V_14B_480p_cfg_step_distill_rank64_bf16.safetensors"

**clip_visions**
cd ComfyUI/models/clip_visions/
```

### 4. 创建 docker 镜像

```
cd /your/path/aoi_useless_docker          # 进入项目文件夹
http_proxy="http://server.url:20171"      #  我这里使用代理, 修改为代理url和端口
mv Dockerfile ./ComfyUI/ && mv sources.list ./ComfyUI/ && cd ComfyUI/      # 复制 Dockerfile sources.list 到 ComfyUI/ 

# 创建镜像
DOCKER_BUILDKIT=1 docker build --build-arg http_proxy=${http_proxy} --build-arg https_proxy=${http_proxy} -t comfyui_docker .
```

### 5. 修改环境变量和启动 docker 容器

```
# 修改 .env 环境变量 (服务器端使用 nano 修改)
cd  /your/path/aoi_useless_docker          # 进入项目文件夹
nano .env                                  # 修改 USER_COMFYUI 路径为 /your/path/aoi_useless_docker/ComfyUI

# 启动docker 容器
docker compose up -d
```
