### 4. Docker-Image erstellen

```
cd /your/path/aoi_useless_docker          # Wechsel in den Projektordner
http_proxy="http://server.url:20171"      # Ich verwende hier einen Proxy; ersetze ihn durch deine Proxy-URL und -Port
mv Dockerfile ./ComfyUI/ && mv sources.list ./ComfyUI/ && cd ComfyUI/      # Verschiebe Dockerfile und sources.list nach ComfyUI/

# Image erstellen
DOCKER_BUILDKIT=1 docker build --build-arg http_proxy=${http_proxy} --build-arg https_proxy=${http_proxy} -t comfyui_docker .
```

### 5. Umgebungsvariablen aktualisieren und den Docker-Container starten

```
# Bearbeite die .env-Variablen (bearbeite auf dem Server mit nano)
cd  /your/path/aoi_useless_docker          # Wechsel in den Projektordner
nano .env                                  # Setze USER_COMFYUI auf /your/path/aoi_useless_docker/ComfyUI

# Docker-Container starten
docker compose up -d
```
