### 4. Construire l’image Docker

```
cd /your/path/aoi_useless_docker          # Entre dans le dossier du projet
http_proxy="http://server.url:20171"      # J’utilise un proxy ici ; remplace-le par ton URL et port
mv Dockerfile ./ComfyUI/ && mv sources.list ./ComfyUI/ && cd ComfyUI/      # Déplace Dockerfile et sources.list vers ComfyUI/

# Construire l’image
DOCKER_BUILDKIT=1 docker build --build-arg http_proxy=${http_proxy} --build-arg https_proxy=${http_proxy} -t comfyui_docker .
```

### 5. Mettre à jour les variables d’environnement et démarrer le conteneur Docker

```
# Modifier les variables .env (édite-les sur le serveur avec nano)
cd  /your/path/aoi_useless_docker          # Entre dans le dossier du projet
nano .env                                  # Remplace USER_COMFYUI par /your/path/aoi_useless_docker/ComfyUI

# Démarrer le conteneur Docker
docker compose up -d
```
