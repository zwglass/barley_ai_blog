### 4. Docker 이미지 빌드

```
cd /your/path/aoi_useless_docker          # 프로젝트 폴더로 이동
http_proxy="http://server.url:20171"      # 여기서는 프록시를 사용합니다. 자신의 프록시 URL과 포트로 변경하세요
mv Dockerfile ./ComfyUI/ && mv sources.list ./ComfyUI/ && cd ComfyUI/      # Dockerfile과 sources.list를 ComfyUI/로 이동

# 이미지 빌드
DOCKER_BUILDKIT=1 docker build --build-arg http_proxy=${http_proxy} --build-arg https_proxy=${http_proxy} -t comfyui_docker .
```

### 5. 환경 변수를 업데이트하고 Docker 컨테이너 시작

```
# .env 환경 변수 수정 (서버에서 nano로 편집)
cd  /your/path/aoi_useless_docker          # 프로젝트 폴더로 이동
nano .env                                  # USER_COMFYUI를 /your/path/aoi_useless_docker/ComfyUI 로 변경

# Docker 컨테이너 시작
docker compose up -d
```
