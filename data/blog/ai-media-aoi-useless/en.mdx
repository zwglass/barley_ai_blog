### 4. Build the Docker image

```
cd /your/path/aoi_useless_docker          # Enter the project folder
http_proxy="http://server.url:20171"      # I use a proxy here; replace with your proxy URL and port
mv Dockerfile ./ComfyUI/ && mv sources.list ./ComfyUI/ && cd ComfyUI/      # Move Dockerfile and sources.list into ComfyUI/

# Build the image
DOCKER_BUILDKIT=1 docker build --build-arg http_proxy=${http_proxy} --build-arg https_proxy=${http_proxy} -t comfyui_docker .
```

### 5. Update environment variables and start the Docker container

```
# Edit the .env variables (edit on the server with nano)
cd  /your/path/aoi_useless_docker          # Enter the project folder
nano .env                                  # Change USER_COMFYUI to /your/path/aoi_useless_docker/ComfyUI

# Start the Docker container
docker compose up -d
```
