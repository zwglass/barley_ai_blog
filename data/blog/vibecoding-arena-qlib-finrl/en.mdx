Recreate the nof1.ai website automatically with Codex.

### Install the essentials: Python, Node.js, VS Code (grab them from the official sites below)

```
# Python official site
https://www.python.org/

# Node.js official site; Node.js version (requires >= 20.19.0)
https://nodejs.org/

# VS Code official site
https://code.visualstudio.com/
```

### Install the `gpt-5-codex` CLI

```
# Install gpt-5-codex globally
npm install -g @openai/codex
```

### Configure `gpt-5-codex` environment variables (configure these first when using a relay inside mainland China)

```
# Open the beginning of the ~/.codex/config.toml file and add the following:

model_provider = "crs"
model = "gpt-5-codex"
model_reasoning_effort = "high"
disable_response_storage = true
preferred_auth_method = "apikey"
[model_providers.crs]
name = "crs"
base_url = "https://{relay-domain}/openai"
wire_api = "responses"
requires_openai_auth = true
env_key = "CRS_OAI_KEY"
```

### Enter the project directory in the terminal

```
arena_qlib_finrl="/project/path/arena-qlib-finrl"
mkdir -p "${arena_qlib_finrl}/venv" && cd "${arena_qlib_finrl}/venv"

# Create the Python virtual environment
python3 -m venv .
cd ..

# Activate the virtual environment
source venv/bin/activate

# Create the tools folder, copy generate_project_structure.py into it, and run
python tools/generate_project_structure.py

# Install dependencies
pip install -r requirements.txt

```
