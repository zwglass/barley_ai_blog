使用codex自动复刻 nof1.ai 网站

### 安装基础工具 python nodejs vscode; 从下面的官网下载并安装

```
# python 官网
https://www.python.org/

# Node.js 官网; Node.js版本（需要 >= 20.19.0）
https://nodejs.org/

# vscode 官网
https://code.visualstudio.com/
```

### 安装 gpt-5-codex 命令

```
# 全局安装 gpt-5-codex
npm install -g @openai/codex
```

### 配置 gpt-5-codex 环境变量 (国内使用中转连接需要先配置环境变量)

```
# 打开 ~/.codex/config.toml 文件开头添加以下配置:

model_provider = "crs"
model = "gpt-5-codex"
model_reasoning_effort = "high"
disable_response_storage = true
preferred_auth_method = "apikey"
[model_providers.crs]
name = "crs"
base_url = "https://{中转域名}/openai"
wire_api = "responses"
requires_openai_auth = true
env_key = "CRS_OAI_KEY"
```

### 终端进入项目文件夹

```
arena_qlib_finrl="/project/path/arena-qlib-finrl"
mkdir -p "${arena_qlib_finrl}/venv" && cd "${arena_qlib_finrl}/venv"

# 创建python虚拟环境
python3 -m venv .
cd ..

# 激活python拟环境
source venv/bin/activate

# 创建tools文件夹, 把generate_project_structure.py复制到tools文件夹下并运行
python tools/generate_project_structure.py

# 安装依赖
pip install -r requirements.txt

```
