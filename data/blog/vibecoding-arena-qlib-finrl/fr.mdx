Recréez automatiquement le site nof1.ai avec Codex.

### Installez l’essentiel : Python, Node.js, VS Code (téléchargez-les depuis les sites officiels ci-dessous)

```
# Site officiel de Python
https://www.python.org/

# Site officiel de Node.js ; version requise (>= 20.19.0)
https://nodejs.org/

# Site officiel de VS Code
https://code.visualstudio.com/
```

### Installez la CLI `gpt-5-codex`

```
# Installez gpt-5-codex globalement
npm install -g @openai/codex
```

### Configurez les variables d’environnement de `gpt-5-codex` (à paramétrer en priorité si vous utilisez un relais en Chine continentale)

```
# Ouvrez le début du fichier ~/.codex/config.toml et ajoutez :

model_provider = "crs"
model = "gpt-5-codex"
model_reasoning_effort = "high"
disable_response_storage = true
preferred_auth_method = "apikey"
[model_providers.crs]
name = "crs"
base_url = "https://{relay-domain}/openai"
wire_api = "responses"
requires_openai_auth = true
env_key = "CRS_OAI_KEY"
```

### Accédez au dossier du projet dans le terminal

```
arena_qlib_finrl="/project/path/arena-qlib-finrl"
mkdir -p "${arena_qlib_finrl}/venv" && cd "${arena_qlib_finrl}/venv"

# Créez l’environnement virtuel Python
python3 -m venv .
cd ..

# Activez l’environnement virtuel
source venv/bin/activate

# Créez le dossier tools, copiez generate_project_structure.py et exécutez-le
python tools/generate_project_structure.py

# Installez les dépendances
pip install -r requirements.txt

```

### Définissez la clé API

```
# Modifiez le fichier conf/.env
```

### Téléchargez les données de marché

```
python -m src.qlib_init
```

### Lancez l’arène de trading IA

```
python -m src.arena
```

### Consultez les résultats de trading dans votre navigateur

```
streamlit run web_dashboard.py
```
