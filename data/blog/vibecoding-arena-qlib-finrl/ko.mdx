Codex를 사용해 nof1.ai 웹사이트를 자동으로 재구현합니다.

### 필수 도구 설치: Python, Node.js, VS Code (아래 공식 사이트에서 다운로드)

```
# Python 공식 사이트
https://www.python.org/

# Node.js 공식 사이트; 요구 버전 (>= 20.19.0)
https://nodejs.org/

# VS Code 공식 사이트
https://code.visualstudio.com/
```

### `gpt-5-codex` CLI 설치

```
# gpt-5-codex를 전역으로 설치
npm install -g @openai/codex
```

### `gpt-5-codex` 환경 변수를 설정 (중국 본토에서 중계 서버를 사용할 경우 먼저 설정)

```
# ~/.codex/config.toml 파일의 처음에 다음 내용을 추가합니다:

model_provider = "crs"
model = "gpt-5-codex"
model_reasoning_effort = "high"
disable_response_storage = true
preferred_auth_method = "apikey"
[model_providers.crs]
name = "crs"
base_url = "https://{relay-domain}/openai"
wire_api = "responses"
requires_openai_auth = true
env_key = "CRS_OAI_KEY"
```

### 터미널에서 프로젝트 디렉터리로 이동

```
arena_qlib_finrl="/project/path/arena-qlib-finrl"
mkdir -p "${arena_qlib_finrl}/venv" && cd "${arena_qlib_finrl}/venv"

# Python 가상환경 생성
python3 -m venv .
cd ..

# 가상환경 활성화
source venv/bin/activate

# tools 폴더를 만들고 generate_project_structure.py를 복사해 실행
python tools/generate_project_structure.py

# 의존성 설치
pip install -r requirements.txt

```
