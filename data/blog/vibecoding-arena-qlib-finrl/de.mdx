Repliziere die Website nof1.ai automatisch mit Codex.

### Installiere die Grundausstattung: Python, Node.js, VS Code (lade sie von den offiziellen Seiten unten herunter)

```
# Offizielle Python-Website
https://www.python.org/

# Offizielle Node.js-Website; benötigte Node.js-Version (>= 20.19.0)
https://nodejs.org/

# Offizielle VS-Code-Website
https://code.visualstudio.com/
```

### Installiere die `gpt-5-codex`-CLI

```
# Installiere gpt-5-codex global
npm install -g @openai/codex
```

### Konfiguriere die `gpt-5-codex`-Umgebungsvariablen (bei Nutzung eines Relays in Festlandchina zuerst festlegen)

```
# Öffne den Anfang der Datei ~/.codex/config.toml und füge Folgendes hinzu:

model_provider = "crs"
model = "gpt-5-codex"
model_reasoning_effort = "high"
disable_response_storage = true
preferred_auth_method = "apikey"
[model_providers.crs]
name = "crs"
base_url = "https://{relay-domain}/openai"
wire_api = "responses"
requires_openai_auth = true
env_key = "CRS_OAI_KEY"
```

### Wechsle im Terminal in das Projektverzeichnis

```
arena_qlib_finrl="/project/path/arena-qlib-finrl"
mkdir -p "${arena_qlib_finrl}/venv" && cd "${arena_qlib_finrl}/venv"

# Erstelle die Python-Umgebung
python3 -m venv .
cd ..

# Aktiviere die virtuelle Umgebung
source venv/bin/activate

# Lege den Ordner tools an, kopiere generate_project_structure.py hinein und führe ihn aus
python tools/generate_project_structure.py

# Installiere die Abhängigkeiten
pip install -r requirements.txt

```

### Setze den API-Schlüssel

```
# Bearbeite die Datei conf/.env
```

### Lade Marktdaten herunter

```
python -m src.qlib_init
```

### Starte die KI-Handelsarena

```
python -m src.arena
```

### Untersuche die Handelsergebnisse im Browser

```
streamlit run web_dashboard.py
```
