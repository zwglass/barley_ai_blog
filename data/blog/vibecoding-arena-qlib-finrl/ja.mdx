Codexでnof1.aiサイトを自動的に再構築します。

### 必須ツールをインストールする：Python、Node.js、VS Code（以下の公式サイトからダウンロード）

```
# Python公式サイト
https://www.python.org/

# Node.js公式サイト：必要なバージョン (>= 20.19.0)
https://nodejs.org/

# VS Code公式サイト
https://code.visualstudio.com/
```

### `gpt-5-codex` CLIをインストールする

```
# gpt-5-codexをグローバルにインストール
npm install -g @openai/codex
```

### `gpt-5-codex` の環境変数を設定する（中国本土でリレー接続を利用する場合は先に設定）

```
# ~/.codex/config.toml の冒頭を開き、次を追加します：

model_provider = "crs"
model = "gpt-5-codex"
model_reasoning_effort = "high"
disable_response_storage = true
preferred_auth_method = "apikey"
[model_providers.crs]
name = "crs"
base_url = "https://{relay-domain}/openai"
wire_api = "responses"
requires_openai_auth = true
env_key = "CRS_OAI_KEY"
```

### ターミナルでプロジェクトディレクトリに移動する

```
arena_qlib_finrl="/project/path/arena-qlib-finrl"
mkdir -p "${arena_qlib_finrl}/venv" && cd "${arena_qlib_finrl}/venv"

# Python仮想環境を作成
python3 -m venv .
cd ..

# 仮想環境をアクティブ化
source venv/bin/activate

# toolsフォルダを作成し、generate_project_structure.pyをコピーして実行
python tools/generate_project_structure.py

# 依存関係をインストール
pip install -r requirements.txt

```

### APIキーを設定する

```
# conf/.env ファイルを編集
```

### 市場データをダウンロードする

```
python -m src.qlib_init
```

### AIトレーディングアリーナを起動する

```
python -m src.arena
```

### ブラウザでトレード結果を確認する

```
streamlit run web_dashboard.py
```
